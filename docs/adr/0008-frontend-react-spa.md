# Frontend: React SPA (Vite), not Next.js

AIARAP's frontend is a client-rendered React + TypeScript single-page application (built with Vite), not a server-rendered framework like Next.js. Every surface — Payer portal, Vendor portal, Tenant-facing views — sits entirely behind authentication with no public content and no SEO requirement, so Next.js's server-rendering machinery would be overhead without a corresponding benefit; a plain SPA is simpler to reason about and deploys as static assets (e.g. S3 + CloudFront), while all real business logic and integration work (SAP/Salesforce/Stripe/Textract) lives in the backend API regardless of frontend framework choice. The UI is built on a component library with strong data-grid/table support — the approval matrix editor, RFQ response comparison, and reconciliation reports are all grid-heavy — using a broad-coverage library (e.g. Ant Design or MUI) paired with a dedicated grid component (e.g. AG Grid) for the more complex editable grids, rather than a leaner design-forward library that would require building that grid complexity from scratch.
