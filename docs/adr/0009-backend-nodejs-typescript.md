# Backend: Node.js + TypeScript (NestJS)

**Superseded by [ADR-0039](0039-sap-integration-technology-and-backend-stack.md).** Originally decided: AIARAP's backend is Node.js + TypeScript (NestJS), not Java/Spring Boot — at the time, on the premise that Tenants' SAP systems are reached exclusively via OData/REST, not RFC/BAPI, so Java's one structural advantage (JCo) didn't apply. That premise no longer holds (see ADR-0039) — kept here as a historical record.
