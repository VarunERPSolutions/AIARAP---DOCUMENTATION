# Parking Lot: Open Items

A single running list of every open/unresolved item surfaced across AIARAP's ADRs, schema docs, and build plan — otherwise scattered as inline "open question"/"forward reference" notes that are easy to lose track of. **This doc is maintained continuously, not written once**: a new open item found anywhere else gets a row added here (in addition to wherever it was originally noted), and when an item is resolved its row updates in place — status flips to Resolved, and the Resolution column collapses to a one-line pointer to wherever the decision actually landed (an ADR, a schema table), not a repeated summary of it. Row numbers are permanent even after a row is resolved — several ADRs cite a specific item number in their own text (e.g. "resolves parking lot #59"), so numbers are never reused or renumbered, and a resolved row's number stays even though its content is now minimal.

## How to use this doc

- **Adding an item**: when a new open question/forward-reference surfaces while working on something else, note it inline in that doc (as has been the convention) *and* add a row here in the same edit pass — don't let it exist in only one place.
- **Resolving an item**: update its **Status** to `Resolved`/`Superseded`, collapse **Resolution** to a one-line pointer to wherever the decision actually landed, and go back and update the *source* doc's own inline note so it no longer reads as open. Do this in the same pass as making the decision.
- **Row numbers never change**, even once a row is fully resolved and its detail trimmed to one line — other docs cite specific item numbers directly (e.g. an ADR's own title/text), and renumbering would break those references silently.
