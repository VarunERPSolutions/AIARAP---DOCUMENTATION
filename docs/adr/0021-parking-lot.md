# Parking Lot: Open Items

A single running list of every open/unresolved item surfaced across AIARAP's ADRs, schema docs, and build plan — otherwise scattered as inline "open question"/"forward reference" notes that are easy to lose track of. **This doc is maintained continuously, not written once**: a new open item found anywhere else gets a row added here (in addition to wherever it was originally noted), and when an item is resolved its row is updated in place — status flips to Resolved, a resolution note + pointer to where the decision landed is added, and the source doc's own inline note is updated too. Rows are never deleted, so this stays a full history of what was deferred and why, not just a live TODO.

## How to use this doc

- **Adding an item**: when a new open question/forward-reference surfaces while working on something else, note it inline in that doc (as has been the convention) *and* add a row here in the same edit pass — don't let it exist in only one place.
- **Resolving an item**: when a row's question gets answered, update its **Status** to `Resolved`, fill in **Resolution** with a one-line summary + a link to wherever the decision was actually recorded (an ADR section, a table's new column, a spec line), and go back and update the *source* doc's own inline note so it no longer reads as open. Do this in the same pass as making the decision, consistent with this project's established "write decisions immediately" working convention.
- **Never delete a row** — a resolved item stays as a record of what was once open and how it got closed.
